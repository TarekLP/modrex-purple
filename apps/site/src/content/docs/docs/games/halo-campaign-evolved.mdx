Halo: Campaign Evolved support covers standard Unreal pak mods and UE4SS Lua mods.

<GameFacts game="hce" />

## Mod source

Halo: Campaign Evolved uses the Nexus Mods catalog. ModWorkshop is not available for HCE in Modrex, so Browse always shows Nexus Mods.

## Install targets

Modrex routes each archive to the folder the game's loader reads, based on the archive's contents:

- **Pak mods** — pak mods go into `Meteorite/Content/Paks/~mods`.
- **UE4SS mods** — UE4SS Lua mods (`Scripts/main.lua`) go into `Meteorite/Binaries/Win64/ue4ss/Mods`. UE4SS itself is not installed by Modrex; a Nexus mod is used to install the loader, and Modrex detects the proxy DLL in the binaries folder.

## UE4SS

Halo: Campaign Evolved runs on a recent Unreal Engine, so UE4SS Lua mods require the experimental UE4SS build for that engine version. Install UE4SS through Nexus Mods so Modrex recognizes the loader, then Lua mods install into the `ue4ss/Mods` folder.

## Priority

Pak mods in `~mods` use numeric filename prefixes when Modrex needs to preserve order on disk. The UE4SS mods target is directory-based and is not renamed for priority.
